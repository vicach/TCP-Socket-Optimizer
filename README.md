# TCP-Socket-Optimizer
Multiplexed TCP Echo Server with socket performance tuning (C/Linux)

Проект посвящен исследованию сетевого стека TCP в ОС Linux. В рамках работы реализовано полнофункциональное клиент-серверное приложение на языке C с использованием механизмов мультиплексирования и инструментов диагностики сетевых параметров.

# Ключевые особенности:
- мультиплексирование ввода-вывода: сервер использует системный вызов `select()`, что позволяет обрабатывать до 10 одновременных TCP-соединений в одном потоке без создания дополнительных процессов;
- диагностика и аудит сокетов: отдельная утилита для проверки состояния и конфигурации сетевых параметров через `getsockopt()`;
- оптимизация производительности: исследовано влияние 7 параметров `setsockopt()` на стабильность и скорость передачи данных.

# Технологический стек:
- язык программирования: C (стандарт POSIX);
- операционная система: Linux (Ubuntu/Debian);
- инструменты: GCC, Wireshark, Linux Socket API.

# Структура проекта:
* `server.c` — многопользовательский эхо-сервер с логикой мультиплексирования;
* `client.c` — интерактивный клиент для проверки связи с сервером;
* `socket_tests.c` — утилита для тестирования и верификации опций сокетов.

# Результаты тестирования
В ходе работы была проведена проверка корректности применения ключевых опций сокетов, таких как `TCP_NODELAY` (отключение алгоритма Нагла), `SO_KEEPALIVE` и управление буферами приема/передачи.

1. Низкоуровневый анализ сети, а именно понимание формирования пакетов и управления сессиями на уровне ядра.
2. Написание инструментов: умение создавать кастомные сканеры и утилиты мониторинга.
3. Работа с Linux, следовательно свободное владение системными вызовами и консолью для диагностики инцидентов.
